# 🦉 Math Quest

A bright, touch-friendly math practice game for kids around 7 years old.

**Play it:** https://emilypoipoi.github.io/math-quest/

## Games
- ➕ Adding, ➖ Taking Away, 🔀 Mix It Up
- ❓ Missing Number (e.g. `3 + ? = 7`)
- 🐊 Bigger or Smaller
- ✖️ Times Tables (×1, ×2, ×5, ×10 and more)

Three levels: 🐣 up to 10 (with pictures to count), 🐥 up to 20, 🦅 up to 100.
Each round is 10 questions. First-try answers earn ⭐ stars, and every 15 stars unlocks a sticker.
The 🗣️ button reads the question aloud.

## Install on a phone or iPad
- **iPhone / iPad (Safari):** Share → *Add to Home Screen*
- **Android (Chrome):** menu ⋮ → *Install app*

It works offline after the first visit. Progress is saved on the device.

## Tech
A single `index.html` (no build step) + `manifest.json` + `sw.js` service worker, hosted on GitHub Pages.
